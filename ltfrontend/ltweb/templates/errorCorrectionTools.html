Tutorial

The button to finish the tutorial is at the bottom of the page.
  • The goal is to correct the English Automatic Transcript with Errors on the right side to get the same text as in the English Reference on the left side. The differences are bold in both texts. If something is missing in comparison to the other text, a long underscore is used for that.
  • To start a correction, select the text you want to correct.
  • Unmute the microphone.
  • Make a correction, for example, it's a slash not a hyphen.
  • Wait some seconds until the system corrects the selected text, check with help of the reference on the left side if the text is correct.
  • If not, you can try again or make a new selection if you think the first selection had too many or too less context, in general, how much you select is your own decision.
  • The long underscores are only a visualization for you, the correction system does not see them. Therefore, do not mention these underscores in your corrections.
  • To insert only missing parts, you can click instead of selecting some text and speak what should be inserted, for example, insert operating.
  • Operating with o in the beginning.
  • You can say something like "undo all corrections" to undo all corrections from the current selection or something like "undo the last correction" to undo only the last correction.
  • Pay attention if you introduced new errors. Please correct your introduced errors too because in the end both texts should be the same.
  • If you think there are too many background noises, unmute only the microphone when you start to speak and mute it afterwards.
  • You can open this tutorial again by clicking on the tutorial button.
  • You can pause your current session by clicking on the pause button.
  • If you pause more than two times your session by clicking on the tutorial or pause button, the session is aborted and a new text is open. Avoid to that, but if you have reasons for it, it is no problem.
  • If you are done correcting (either you corrected all errors or gave up to correct the remaining errors), do a new text by clicking next text or exit the correction by clicking on end lecture, if you open the link again, you can continue with a new text.

Pause

You can pause twice during the correction of a text, after finishing the third pause a new text is opened. That is no problem. Pause if you need a pause or you have something important to do, but do not pause to try to accelerate your correction times.
